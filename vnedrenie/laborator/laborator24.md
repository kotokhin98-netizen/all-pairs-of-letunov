### 2. Краткие теоретические сведения

#### 🔹 Файловая структура Linux

В Linux **файлами** считаются:
- Обычные файлы
- Каталоги
- Специальные файлы (периферийные устройства)

> ✅ Доступ ко всем файлам однотипный — обеспечивает независимость программ от особенностей ввода/вывода.

**Иерархия каталогов (древовидная структура):**

| Каталог | Назначение |
|---------|-----------|
| `/bin` | Выполняемые командные программы и shell-процедуры |
| `/tmp` | Временные файлы |
| `/usr` | Каталоги пользователей |
| `/etc` | Административные утилиты и конфигурационные файлы |
| `/dev` | Специальные файлы устройств |

**Обозначения каталогов:**
- `.` — текущий каталог
- `..` — родительский каталог
- `/` — корневой каталог

**Полное имя файла:** `/home/student/file.txt`

#### 🔹 Связи с файлами (команда `ln`)

```bash
# Жёсткая ссылка
ln <файл1> <файл2>

# Символическая ссылка
ln -s <файл1> <файл2>
```

> 📌 Символическая связь — особый файл, содержащий путь к целевому файлу.

#### 🔹 Права доступа к файлам

**3 уровня доступа:**
| Уровень | Обозначение | Описание |
|---------|-------------|----------|
| Владелец | `u` (user) | Права создателя файла |
| Группа | `g` (group) | Права пользователей группы |
| Остальные | `o` (others) | Права всех остальных |

**Типы прав:**
| Символ | Право | Описание |
|--------|-------|----------|
| `r` | Read | Чтение |
| `w` | Write | Запись |
| `x` | Execute | Выполнение |
| `-` | — | Нет права |

**Типы файлов (первый символ в `ls -l`):**
| Символ | Тип файла |
|--------|-----------|
| `-` | Обычный файл |
| `d` | Каталог |
| `l` | Символическая ссылка |
| `b` | Блок-ориентированное устройство |
| `c` | Байт-ориентированное устройство |

**Пример вывода `ls -l`:**
```

│││││││││  │    │    │   │  │  │      │

│││││││││  │    │    │   │  │  └──────── время
│││││││││  │    │    │   │  └─────────── дата
│││││││││  │    │    │   └────────────── размер (байт)
│││││││││  │    │    └────────────────── группа
│││││││││  │    └─────────────────────── владелец
│││││││││  └──────────────────────────── число ссылок
││││││││└─────────────────────────────── права: остальные
│││││││└──────────────────────────────── права: группа
││││││└───────────────────────────────── права: владелец
│││││└────────────────────────────────── тип файла
```

#### 🔹 Управление правами: `chmod`

```bash
# Символьный режим
chmod [u/g/o/a][+/-/=][r/w/x] файл

# Примеры:
chmod g+rw,o+r file.1    # добавить чтение/запись группе, чтение остальным
chmod o-w file.1         # убрать запись у остальных
chmod 755 script.sh      # числовой режим (rwxr-xr-x)
```

**Числовой режим (восьмеричная система):**
| Право | Значение |
|-------|----------|
| `r` | 4 |
| `w` | 2 |
| `x` | 1 |
| `-` | 0 |

> Пример: `7 = 4+2+1 = rwx`, `5 = 4+1 = r-x`

#### 🔹 Основные команды работы с файлами

| Команда | Описание |
|---------|----------|
| `>file` | Создание/очистка файла |
| `cat file` | Вывод содержимого файла |
| `cat f1 f2 > f12` | Конкатенация файлов |
| `mv f1 f2` | Переименование/перемещение |
| `cp f1 f2` | Копирование файла |
| `rm file` | Удаление файла |
| `mkdir dir` | Создание каталога |
| `rm -r dir` | Удаление каталога рекурсивно |
| `cd [dir]` | Смена каталога |
| `pwd` | Показать текущий каталог |

#### 🔹 Ключи команды `ls`

| Ключ | Описание |
|------|----------|
| `-l` | Подробный список с атрибутами |
| `-a` | Показать скрытые файлы (начинающиеся с `.`) |
| `-t` | Сортировка по времени изменения |
| `-s` | Показать размер в блоках |
| `-d` | Показать каталог, а не его содержимое |
| `-i` | Показать inode-номер файла |
| `-R` | Рекурсивный вывод подкаталогов |
| `-F` | Добавить `/` к каталогам, `*` к исполняемым |

#### 🔹 Поиск по шаблону: `grep`

```bash
grep [-vcilns] "шаблон" файл
```

| Ключ | Описание |
|------|----------|
| `-v` | Вывести строки **без** шаблона |
| `-c` | Только количество совпадений |
| `-i` | Игнорировать регистр |
| `-l` | Только имена файлов с совпадениями |
| `-n` | Нумеровать строки |
| `-s` | Только код завершения |

**Примеры:**
```bash
# Найти файлы с "student" и расширением .txt
grep -l student *.txt

# Найти пользователя на терминале tty23
who | grep tty23
```

### 5. Контрольные вопросы

**1. Что считается файлами в ОС Linux?**  
> В Linux файлами считаются обычные файлы, каталоги, а также специальные файлы, соответствующие периферийным устройствам (принтеры, диски, терминалы). Это обеспечивает унифицированный доступ ко всем ресурсам системы.

**2. Объясните назначение связей с файлами и способы их создания.**  
> Связи позволяют одному файлу иметь несколько имён/путей доступа:
> - **Жёсткая ссылка** (`ln`): указывает на inode файла, не работает для каталогов и разных ФС
> - **Символическая ссылка** (`ln -s`): отдельный файл с путём к цели, может ссылаться на каталоги и удалённые ФС

**3. Что определяет атрибуты файлов и каким образом их можно просмотреть и изменить?**  
> Атрибуты определяют права доступа (r/w/x) для владельца, группы и остальных.  
> - Просмотр: `ls -l`  
> - Изменение: `chmod [u/g/o][+/-][r/w/x] файл` или `chmod XXX файл` (восьмеричный код)

**4. Какие методы создания и удаления файлов, каталогов Вы знаете?**  
> **Создание:**  
> - Файлы: `touch file`, `>file`, `echo "text" > file`, текстовые редакторы  
> - Каталоги: `mkdir dir`, `mkdir -p path/to/dir`  
>   
> **Удаление:**  
> - Файлы: `rm file`, `rm -i file` (с подтверждением)  
> - Каталоги: `rm -r dir`, `rmdir dir` (только пустые)

**5. В чем заключается поиск по шаблону?**  
> Поиск по шаблону (`grep`) позволяет находить строки/файлы, содержащие заданный текст или регулярное выражение. Поддерживает регистронезависимый поиск, инверсию, подсчёт совпадений и вывод только имён файлов.

**6. Какой командой можно получить список работающих пользователей и сохранить его в файле?**  
```bash
who > users.log           # сохранить список пользователей
w >> report.txt           # добавить расширенную информацию
who | grep tty > active.txt  # фильтрация по терминалу
```
