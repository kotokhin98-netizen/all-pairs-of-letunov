### 2. Краткие теоретические сведения

В ОС Linux взаимодействие с системой осуществляется через интерпретатор команд (shell), чаще всего **bash**.

**Основные отличия синтаксиса от Windows CMD:**
| Действие | Windows CMD | Linux Bash |
|----------|-------------|------------|
| Копирование | `copy` | `cp` |
| Удаление файла | `del` | `rm` |
| Удаление папки | `rd` | `rm -r` или `rmdir` |
| Создание папки | `md` | `mkdir` |
| Просмотр файла | `type` | `cat` |
| Очистка экрана | `cls` | `clear` |
| Смена промпта | `prompt \|` | `PS1="\| "` |

**Структура путей:**
*   Разделитель каталогов: `/` (прямой слеш).
*   Текущий каталог: `.`
*   Родительский каталог: `..`
*   Домашний каталог пользователя: `~` или `/home/user`

#### Шаг 7. Изменение строки приглашения (Пункт 15 - Вариант 3)
По заданию варианта №3 необходимо изменить строку приглашения на символ `|`.


*После ввода этой команды строка ввода изменится на:*

### 5. Контрольные вопросы

**1. Что такое командная строка в Linux?**
Это интерфейс взаимодействия пользователя с операционной системой посредством ввода текстовых команд. В Ubuntu по умолчанию используется оболочка **bash** (Bourne Again SHell).

**2. Чем отличается команда `cp` от `mv`?**
*   `cp` (copy) — создает копию файла или каталога в новом месте, исходный файл остается.
*   `mv` (move) — перемещает файл или переименовывает его. Исходный файл исчезает со старого места.

**3. Как посмотреть содержимое файла без открытия редактора?**
С помощью команды `cat <имя_файла>`. Также можно использовать `less` или `more` для постраничного просмотра больших файлов.

**4. Как изменить права доступа к файлу?**
С помощью команды `chmod`. Например, `chmod +x script.sh` добавляет право на выполнение, а `chmod 755 file` устанавливает права `rwxr-xr-x`.

**5. В чем отличие жестких и символических ссылок?**
*   **Жесткая ссылка (`ln`):** указывает на тот же inode (физическое место на диске), что и оригинал. Не работает для каталогов и разных файловых систем.
*   **Символическая ссылка (`ln -s`):** это отдельный файл-указатель, содержащий путь к оригиналу. Работает как ярлык в Windows.
