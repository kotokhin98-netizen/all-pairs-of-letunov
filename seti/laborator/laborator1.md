### 1. Структурированная кабельная система (СКС)

#### 🔹 Определение
**СКС (Структурированная Кабельная Система)** — универсальная телекоммуникационная инфраструктура здания или комплекса зданий, обеспечивающая передачу сигналов всех типов:
- 🗣️ Речевые сигналы (телефония, голосовая связь)
- 💻 Информационные данные (компьютерные сети, Интернет)
- 📺 Видеосигналы (видеонаблюдение, телевидение)

<img width="220" height="154" alt="image" src="https://github.com/user-attachments/assets/18b5bcc1-3b30-440c-861d-88a9d6c34300" />

#### 🔹 Ключевые особенности СКС
```
✅ Устанавливается ДО определения конкретных требований пользователей
✅ Поддерживает несколько поколений сетевого оборудования
✅ Обеспечивает скорость передачи: 100 Кбит/с — 10 Гбит/с
✅ Гарантирует срок службы 15-25 лет
✅ Позволяет легко масштабировать и модернизировать сеть
```

#### 🔹 Подсистемы СКС (по стандарту ISO/IEC 11801)

```
┌─────────────────────────────────────────┐
│ 1. МАГИСТРАЛЬНАЯ ПОДСИСТЕМА             │
│    КОМПЛЕКСА ЗДАНИЙ                     │
│    • Соединяет кабельные системы зданий │
│    • Среда: оптоволокно + витая пара    │
│    • Длина: до 2-3 км (для телефонии)   │
├─────────────────────────────────────────┤
│ 2. МАГИСТРАЛЬНАЯ ПОДСИСТЕМА ЗДАНИЯ      │
│    • Соединяет распределительные пункты │
│      этажей между собой                 │
│    • Информационная подсистема:         │
│      оптоволокно (одномод/многомод)     │
│    • Речевая подсистема: многопарные    │
│      кабели                             │
├─────────────────────────────────────────┤
│ 3. ГОРИЗОНТАЛЬНАЯ ПОДСИСТЕМА            │
│    • Соединяет рабочие места с РП этажа │
│    • Среда: витая пара ≥ Cat.5          │
│    • Макс. длина канала: 100 метров     │
│    • >90% всех кабелей СКС              │
└─────────────────────────────────────────┘
```

#### 🔹 Преимущества СКС перед раздельными сетями

| Преимущество | Описание |
|-------------|----------|
| 🔄 Универсальность | Передача разнотипных сигналов по единой инфраструктуре |
| 📈 Масштабируемость | Поддержка нескольких поколений сетевого оборудования |
| 🔌 Совместимость | Интерфейсы позволяют подключать любое оборудование |
| ⚡ Скорость | Диапазон от 100 Кбит/с до 10 Гбит/с |
| 🔧 Простота обслуживания | Снижение трудозатрат на администрирование |
| 🌐 Мультипротокольность | Одновременное использование разных сетевых протоколов |
| 💰 Экономичность | Стандартизация снижает стоимость комплектующих |
| 🚶 Мобильность пользователей | Перемещение без изменения сетевых настроек |
| 📋 Прозрачность | Все интерфейсы промаркированы и документированы |

#### 🔹 Администрирование СКС
- **Маркировка**: порты, кабели, панели, кроссы
- **Документация**: схемы, таблицы соответствий, журналы изменений
- **Цветовое кодирование** (по TIA/EIA-606-A):
  - 🔵 Магистраль комплекса зданий
  - 🟢 Магистраль здания
  - 🟡 Горизонтальная подсистема
  - 🔴 Внешние подсистемы / не относящиеся к СКС

#### 🔹 Распределительные пункты (РП)

| Тип шкафа | Применение | Вместимость |
|----------|-----------|------------|
| 🗄️ Напольный шкаф | Крупные РП, серверные | Сотни линий + оборудование |
| 🗂️ Телекоммуникационная стойка | При отсутствии требований к защите | Аналогично шкафу, дешевле |
| 📦 Настенный шкаф | Небольшие РП, нет спецпомещения | До 50-100 линий |

> ⚠️ **Рекомендация**: На каждом этаже — минимум 1 РП. При площади этажа >1000 м² — дополнительный РП.

#### 🔹 Принцип работы
- Благодаря соосности проводников и определённому соотношению диаметров внутри кабеля образуется **режим стоячей волны**
- Это снижает потери электромагнитной энергии на излучение почти до нуля
- Экран защищает от внешних электромагнитных помех

#### 🔹 Классификация по волновому сопротивлению

| Сопротивление | Применение | Примеры |
|--------------|-----------|---------|
| **50 Ом** ⭐ | Радиоэлектроника, компьютерные сети | RG-8, RG-11, RG-58 |
| **75 Ом** 📺 | Телевидение, видеотехника | RG-6 (РК-75) |
| **93 Ом** ⚡ | Импульсная техника, спеццели | RG-62 (ARCNet) |

#### 🔹 Категории коаксиальных кабелей для сетей

| Категория | Стандарт | Характеристики | Применение |
|----------|----------|---------------|-----------|
| **RG-58** (Thinnet) | 10BASE2 | • Диаметр ~6 мм • Гибкий • До 185 м • 10 Мбит/с | Наиболее распространён в ранних ЛВС |
| **RG-8/RG-11** (Thicknet) | 10BASE5 | • Диаметр ~12 мм • Жёсткий • До 500 м • 10 Мбит/с | Магистральные сегменты |
| **RG-6** | — | 75 Ом, телевизионный | Кабельное ТВ, видеонаблюдение |
| **RG-62** | ARCNet | 93 Ом | Устаревшие сети ARCNet |

#### 🔹 Особенности монтажа коаксиального Ethernet
- **Thinnet (RG-58)**:
  - T-коннекторы BNC для подключения к сетевой карте
  - Терминаторы на концах сегмента
  - Простота монтажа, но ограничена длина

- **Thicknet (RG-8)**:
  - Трансиверы AUI с «вампирчиками» (пронзающими отводами)
  - Сложнее и дороже в установке
  - Большая дальность передачи

#### 🔹 Вспомогательные элементы коаксиального тракта

```
1️⃣ Коаксиальные разъёмы — подключение к оборудованию
2️⃣ Переходы — соединение кабелей с разными разъёмами
3️⃣ Тройники/ответвители — разветвление сетей
4️⃣ Трансформаторы — согласование волнового сопротивления
5️⃣ Нагрузки (оконечные/проходные) — установка режима волны
6️⃣ Аттенюаторы — ослабление сигнала до нужного уровня
7️⃣ Ферритовые вентили — поглощение обратной волны
8️⃣ Грозоразрядники — защита от атмосферных разрядов
9️⃣ Переключатели/реле — коммутация линий
🔟 Коаксиально-волноводные переходы — стыковка с другими типами линий
```

#### 🔹 Типы коаксиальных разъёмов

| Тип | Сопротивление | Применение |
|-----|--------------|-----------|
| **Тип N** | 50 Ом | Профессиональное оборудование, антенны |
| **BNC** ⭐ | 50 Ом | Ethernet 10BASE2, видеонаблюдение |
| **Тип UHF** | 50 Ом | Радиолюбительская техника |
| **Тип C** | 50/75 Ом | Универсальный |
| **RCA «Тюльпан»** | 75 Ом | Бытовая аудио/видеотехника |

### 3. Витая пара (Twisted Pair)

#### 🔹 Принцип свивания проводников
- Проводники скручиваются с небольшим числом витков на единицу длины
- **Цель**: 
  - Повышение связи между проводниками одной пары
  - Компенсация внешних ЭМ-помех (одинаково влияют на оба провода)
  - Снижение взаимных наводок при передаче дифференциальных сигналов
- В кабелях **Cat.5 и выше** пары свиваются с **разным шагом** для снижения межпарных наводок

#### 🔹 Классификация по экранированию

| Аббревиатура | Расшифровка | Конструкция | Применение |
|-------------|------------|------------|-----------|
| **UTP** | Unshielded Twisted Pair | Без экрана | Офисные помещения, низкий уровень помех |
| **FTP** (S/UTP) | Foiled Twisted Pair | Общий экран из фольги | Помещения с умеренными помехами |
| **STP** | Shielded Twisted Pair | Экран для каждой пары | Промышленные условия |
| **S/FTP** | Shielded Foiled Twisted Pair | Фольга на парах + медная оплётка | Высокие требования к защите |
| **S/STP** | Screened Shielded Twisted Pair | Экран на парах + общий экран | Критичные объекты |

> ⚠️ **Важно**: Экран соединяется с дренажным проводом по всей длине. При монтаже необходимо сохранять целостность экрана!

#### 🔹 Конструкция витопарного кабеля

```
🔸 Проводники:
   • Монолитная медная проволока 0,4–0,6 мм (26–22 AWG)
   • Стандарт: 0,51 мм (24 AWG) для 4-парных кабелей

🔸 Изоляция проводника (~0,2 мм):
   • ПВХ (PVC) — базовый вариант
   • Полипропилен (PP), полиэтилен (PE) — Cat.5 и выше
   • Вспененный полиэтилен — низкие диэлектрические потери
   • Тефлон — широкий температурный диапазон

🔸 Внешняя оболочка:
   • ПВХ — для помещений
   • ПЭ — для внешней прокладки (УФ-стойкий)
   • НГ (негорючий) — для пожароопасных зон
```

#### 🔹 Одножильный vs Многожильный кабель

| Параметр | Одножильный (Solid) | Многожильный (Stranded) |
|---------|-------------------|----------------------|
| Конструкция | Одна медная жила | Несколько тонких жил |
| Гибкость | ❌ Низкая, ломается при изгибах | ✅ Высокая, устойчив к скручиванию |
| Затухание | ✅ Меньше | ❌ Больше |
| Монтаж в розетки | ✅ Идеален для «врезания» | ❌ Тонкие жилы могут разрезаться |
| Применение | Стационарная прокладка в стенах, коробах | Патч-корды, подключение оборудования |

#### 🔹 Категории витой пары (Таблица 1.1)

| Категория | Полоса частот | Макс. скорость | Пар | Применение |
|----------|--------------|---------------|-----|-----------|
| **CAT1** | 0,1 МГц | ~1 Мбит/с | 1 | Телефония, модемы |
| **CAT2** | 1 МГц | до 4 Мбит/с | 2 | Token Ring, Arcnet (устар.) |
| **CAT3** | 16 МГц | 10 Мбит/с (100 Мбит/с по T4) | 4 | 10BASE-T, телефония, 100BASE-T4 |
| **CAT4** | 20 МГц | до 16 Мбит/с | 4 | Token Ring (устар.) |
| **CAT5** | 100 МГц | 100 Мбит/с (2 пары) | 4 | 100BASE-TX, телефония |
| **CAT5e** ⭐ | 125 МГц | **100 Мбит/с** (2 пары) / **1 Гбит/с** (4 пары) | 4 | **Самый распространённый для ЛВС** |
| **CAT6** | 250 МГц | 1 Гбит/с (до 100 м) / 10 Гбит/с (до 50 м) | 4 | Gigabit Ethernet, новые проекты |
| **CAT6a** | 500 МГц | 10 Гбит/с (до 100 м) | 4 | Высокоскоростные ЦОД |
| **CAT7** | 600–700 МГц | 10 Гбит/с | 4 (экранир.) | Профессиональные СКС, экранирование |

> ⚠️ **Требование**: Каждая витая пара должна иметь волновое сопротивление **100±25 Ом**, иначе сигнал искажается.

#### 🔹 Схемы обжима разъёма RJ-45

##### 🔸 Прямой кабель (стандартный) — для соединения ПК ↔ Коммутатор/Хаб

**Стандарт EIA/TIA-568B (наиболее распространён в РФ):**

```
Контакт │ Цвет жилы (сторона 1) │ Цвет жилы (сторона 2)
────────┼───────────────────────┼───────────────────────
   1    │ Бело-оранжевый       │ Бело-оранжевый
   2    │ Оранжевый            │ Оранжевый
   3    │ Бело-зелёный         │ Бело-зелёный
   4    │ Синий                │ Синий
   5    │ Бело-синий           │ Бело-синий
   6    │ Зелёный              │ Зелёный
   7    │ Бело-коричневый      │ Бело-коричневый
   8    │ Коричневый           │ Коричневый
```

**Стандарт EIA/TIA-568A (альтернативный):**
- Меняются местами оранжевая и зелёная пары (контакты 1-2 ↔ 3-6)

##### 🔸 Кроссовер (Crossover) — для прямого соединения ПК ↔ ПК или старых хабов

```
Контакт │ Сторона 1 (568B)    │ Сторона 2 (кросс)
────────┼─────────────────────┼─────────────────────
   1    │ Бело-оранжевый     │ Бело-зелёный
   2    │ Оранжевый          │ Зелёный
   3    │ Бело-зелёный       │ Бело-оранжевый
   4    │ Синий              │ Бело-коричневый ⚠️
   5    │ Бело-синий         │ Коричневый ⚠️
   6    │ Зелёный            │ Оранжевый
   7    │ Бело-коричневый    │ Синий ⚠️
   8    │ Коричневый         │ Бело-синий ⚠️
```

> ⚠️ **Примечание**: В оригинальном стандарте кроссовера меняются только пары 1-2 и 3-6. Вариант с перекрёстом всех 4 пар используется в некоторых реализациях.

#### 🔹 Использование пар в разных стандартах

```
🔹 10/100 Мбит/с (100BASE-TX):
   • Используются только 2 пары: 1-2 (передача) и 3-6 (приём)
   • Пары 4-5 и 7-8 свободны — можно использовать для:
     - Второй линии связи (телефон/доп. ПК)
     - Питание PoE (в некоторых реализациях)

🔹 1 Гбит/с (1000BASE-T):
   • Используются ВСЕ 4 пары одновременно
   • Каждая пара работает в дуплексном режиме
   • Свободных пар не остаётся
```

#### 🔹 Проверка обжима кабеля

**Кабельный тестер:**
```
📡 Передатчик → поочерёдно подаёт сигнал на жилы 1→8
📡 Приёмник → загорание светодиодов в том же порядке

✅ ПРАВИЛЬНО: светодиоды 1-8 загораются последовательно на обоих концах
❌ ОШИБКА: пропуски, неверный порядок, отсутствие свечения
```

#### 🔹 Требования к монтажу витой пары

```
⚠️ Минимальный радиус изгиба: 8 × внешний диаметр кабеля
   • Больший изгиб → увеличение наводок или повреждение оболочки

⚠️ Для экранированных кабелей:
   • Сохранять целостность экрана по всей длине
   • Дренажный провод должен быть соединён с экраном разъёма
   • Растяжение/изгиб разрушает экран → потеря помехозащищённости
```

#### 🔹 Преимущества оптоволокна перед медными кабелями

```
✅ Широкая полоса пропускания (до Тбит/с в перспективе)
✅ Малое затухание: 0,2–0,35 дБ/км на λ=1300/1550 нм
✅ Низкий уровень шумов → упрощение обработки сигнала
✅ Полная невосприимчивость к ЭМ-помехам (диэлектрик)
✅ Отсутствие перекрёстных наводок в многожильных кабелях
✅ Высокая защищённость от несанкционированного доступа
✅ Гальваническая развязка элементов сети
✅ Взрыво- и пожаробезопасность
✅ Малый вес и объём при высокой пропускной способности
✅ Удалённое электропитание по отдельным жилам
✅ Срок эксплуатации >25 лет
```

#### 🔹 Окна прозрачности оптического волокна
Диапазоны длин волн с минимальным затуханием:

```
🔹 850 нм  — многомодовое волокно (короткие дистанции)
🔹 1310 нм — одномодовое волокно (стандартное окно)
🔹 1550 нм — одномодовое волокно (минимальное затухание ~0,2 дБ/км)
🔹 1400 нм, 1580 нм — дополнительные окна (современные разработки)
```

> При допустимом затухании 20 дБ расстояние между усилителями может достигать **100 км и более**.

#### 🔹 Сварка оптического волокна (кратко)

**Оборудование:**
- Микроскоп/видеокамеры для позиционирования
- Сварочная камера с электродами и манипуляторами
- Тепловая камера (печь) для термоусадки КДЗС

**Процесс:**
```
1. Разделка кабеля, очистка от гидрофобного материала
2. Установка КДЗС (комплект защиты сварки) на волокна
3. Снятие буферного покрытия (2–3 см), промывка спиртом
4. Скалывание волокна (угол отклонения ≤1,0°)
5. Укладка в V-канавки сварочного аппарата
6. Автоматическая юстировка и совмещение торцов
7. Сварка электрической дугой + микродоводка
8. Проверка прочности (растяжение 200–400 г)
9. Термоусадка КДЗС в печи
10. Укладка в сплайс-кассету/муфту/кросс
```
